# 🎮 Mario Style – 2D Hide-and-Seek Game

A 2D platformer developed in **C++ using the SFML (Simple and Fast Multimedia Library)**. This project combines interactive gameplay, character movement, collision detection, resource management, and visual effects in a Mario-inspired environment.

## 📌 Project Overview

The objective of this project is to develop an interactive 2D game in which the player explores a level, collects coins, avoids obstacles, and manages limited lives while completing the game within a time limit.

The game was developed as a practical programming project to strengthen skills in C++, multimedia programming, event handling, and game mechanics.

## ✨ Features

- **Character Movement:** Interactive player controls for navigating the game environment.
- **Collision Detection:** Handling interactions between the player, the environment, and obstacles.
- **Coin Collection:** Collectible items that encourage exploration and progression.
- **Lives System:** A limited number of lives that adds a challenge to the gameplay.
- **Power-Ups:** Special items that enhance gameplay.
- **Day and Night Cycle:** Visual changes that create different environmental atmospheres.
- **Mini-Map:** A navigation aid that helps the player understand the level layout.
- **Time-Limited Gameplay:** A countdown that challenges the player to complete the level within the available time.
- **2D Graphics:** Visual elements and animations implemented using SFML.

## 🛠️ Technologies Used

- **C++** — Core programming language and game logic.
- **SFML** — Graphics rendering, window management, keyboard input, and multimedia features.
- **Visual Studio** — Development environment and project compilation.

## 🚀 How to Run

1. Clone or download the repository.
2. Install Visual Studio and configure a compatible version of SFML.
3. Configure the project with the appropriate SFML headers and libraries.
4. Build the project in the configuration supported by the source code.
5. Run the generated executable.

*Note: The SFML version and build configuration must match the project setup.*
